# Bloknot — блокнот проектировщика приложений

Приложение для разработчиков: идея проекта фиксируется текстом (кратко в 1–2 предложениях сверху, подробное описание ниже), а на второй вкладке собирается схема из блоков с **исполняемой логикой** — узлы реально вычисляются, живые значения отображаются прямо внутри узлов (dataflow, как в Ryven).

## Документация (читать по порядку)

| Файл | О чём |
|---|---|
| `docs/ARCHITECTURE.md` | Продукт, слои, сквозной пример вычисления, инварианты, частые ошибки |
| `docs/SPEC_CORE.md` | Модели, порты и приведение типов, виджеты параметров, полный реестр всех блоков с формулами |
| `docs/SPEC_STORAGE.md` | SQLite, формат `schema_json` (со блоком `runtime`), автосохранение, миграции, краевые случаи |
| `docs/SPEC_FLOW.md` | Движок dataflow: API, триггеры, псевдокод пересчёта, циклы, песочница eval, ошибки |
| `docs/SPEC_UI.md` | Интерфейс: палитра серых (hex), каждая панель и виджет с размерами, горячие клавиши |
| `docs/CLAUDE_PROMPT.md` | Готовый промт для Клода: границы, инварианты, чек-лист приёмки |

## Как устроено

- Слева — список проектов; справа две вкладки: **«Идея»** (название, краткая идея ≤280 симв., описание) и **«Схема»** (палитра · канва · панель параметров + тулбар runtime).
- **Два типа блоков на одной канве**: исполняемые (число, оператор ±−·÷**, eval с песочницей, get_index, ветка «да/нет», merge, матрицы — numpy опционально) и проектные (сайт → парс → извлечь → использовать) для планирования будущей программы.
- Узел = функция, связь = значение: пересчёт живой (подграф, debounce 200 мс), циклы запрещены, ошибки — состояние узла, а не краш.
- Значения показываются в телах узлов моноширинными чипами; связи пунктирные; inline-виджеты параметров прямо в узлах.
- Автосохранение в SQLite (`data/bloknot.sqlite3`): схема + repr-значения одним JSON.
- Экспорт: Markdown с шагами схемы и Mermaid-диаграммой.

## Статус

v1 реализована: блокнот + вкладки, канва с палитрой/inline-виджетами/чипами, исполняемый dataflow (12 блоков + 9 проектных), песочница eval, Live-режим, автосохранение в SQLite, экспорт Markdown. Запуск: `pip install -r requirements.txt`, затем `python main.py`.

## Визуальный режим (v1.1)

У каждого блока есть вход и выход, даже если блок ничего не считает: приложение используется в первую очередь для визуализации архитектуры. Вычисляются только исполняемые блоки, остальные служат схемой. Портам, добавленным в v1.1, назначены индексы в конце списка, поэтому старые схемы открываются без изменений. Блок `unknown` портов не получает.
