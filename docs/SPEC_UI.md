# SPEC_UI — интерфейс на PySide6

> Обязательная спецификация. Отвечает на вопросы: как всё выглядит, из чего состоит каждый экран и виджет, какие у него размеры/состояния/отступы и как он реагирует на пользователя.

## 1. Общие принципы

1. **Тема в одном месте.** Все цвета — константы в `ui/theme.py`; из них собирается один общий QSS, применяемый к `QApplication` в `app.py`. Виджеты ни разу не пишут цвет руками (иначе минимализм умрёт по кусочкам).
2. **Лестница серых.** Поверхности упорядочены по светлоте: окно темнее всего, панели светлее, элементы ещё светлее, hover/press — дальше по лестнице. Именно это создаёт «сочетающиеся серые», а не случайные оттенки.
3. **Никаких украшений**: без градиентов, теней, ярких цветов, анимаций (максимум — мгновенные состояния hover/press/focus).
4. **Один шрифтовой дуэт**: «Segoe UI» для текста, Consolas для значений и кода.
5. **Микроязыка меток**: служебные подписи — uppercase, 9 pt, `TEXT_MUTED` с letter-spacing 0.5 px («ПРОЕКТЫ», «КРАТКАЯ ИДЕЯ»); данные — обычный регистр, 10 pt, `TEXT_PRIMARY`.

### Базовый QSS (ориентир, расширяется по этим правилам)

```css
QWidget        { background: BG_WINDOW; color: TEXT_PRIMARY; font-family: "Segoe UI"; font-size: 10pt; }
QLineEdit, QPlainTextEdit, QComboBox, QDoubleSpinBox {
    background: BG_ELEMENT; border: 1px solid BORDER; border-radius: 6px; padding: 4px 8px; }
QLineEdit:focus, ...  { border-color: ACCENT; }       /* ореолов нет */
QPushButton     { background: BG_ELEMENT; border: none; border-radius: 6px; padding: 8px 16px; }
QPushButton:hover  { background: BG_ELEMENT_HOVER; }
QPushButton:pressed { background: BG_ELEMENT_PRESSED; }
QToolTip        { background: BG_ELEMENT; color: TEXT_PRIMARY; border: 1px solid BORDER; }
QStatusBar      { background: BG_PANEL; color: TEXT_MUTED; }
QScrollBar      { /* узкий 8px, ползунок BG_ELEMENT, без стрелок */ }
```

Primary-кнопка: `background: ACCENT; color: BG_WINDOW;` hover — чуть светлее (#8a9cb2). Destructive-пункт меню: `color: DANGER`.

## 4. Сайдбар проектов (240 px)

| Элемент | Описание |
|---|---|
| Метка «ПРОЕКТЫ» | uppercase 9 pt `TEXT_MUTED`, отступ 16 px |
| Кнопка «+ Новый проект» | primary, во всю ширину, высота 36 px |
| Список карточек | вертикальный, карточка высотой ~56 px: имя (bold, 10 pt, `TEXT_PRIMARY`) + первая строка идеи (9 pt, `TEXT_SECONDARY`, эллипсис при обрезке) |
| Выбранная карточка | фон `BG_ELEMENT_HOVER` + полоска 2 px `ACCENT` слева |
| ПКМ по карточке | меню: «Удалить» (текст `DANGER`) |
| Удаление | диалог «Удалить проект "<имя>"?» (да/нет) → DELETE → выделить соседний; если проектов больше нет — пустое состояние |
| Пустое состояние | по центру: «Создайте первый проект» (`TEXT_MUTED`) |

Клик по карточке = переключение проекта; несохранённое на моменте переключения не теряется — debounce успеет, но при переключении форсируется flush.

## 5. Вкладка «Схема»

Раскладка: тулбар (40 px) → три колонки: палитра 220 px · канва (растягивается) · панель параметров 260 px.

### 5.1 Тулбар runtime

| Элемент | Поведение |
|---|---|
| «▶ Пересчитать всё» | primary; немедленный полный пересчёт (полезно при Live=off) |
| Тумблер «Авто» | checked по умолчанию = Live. Выключен: пересчёт только по кнопке; узлы с устаревшими данными получают пометку «устарело» |
| «Очистить значения» | сброс всех чипов в «—» (runtime cleared, dirty=True) |
| Подсказка справа | `TEXT_MUTED` 9 pt: «Перетащите блок · выход → вход — связь · Ctrl+колесо — зум · Delete — удалить» |

### 5.2 Палитра

- Группы в порядке: «Данные и код», «Источники», «Извлечение», «Логика», «Действия», «Итог».
- Метка группы: uppercase 9 pt `TEXT_MUTED`; строка блока: высота 32 px, точка 6 px цвета категории + название 10 pt `TEXT_PRIMARY`; фон прозрачный, hover — `BG_ELEMENT`.
- **Drag**: нажатие на строку + смещение >5 px → `QDrag` с `QMimeData`, формат `"application/x-bloknot-node"`, payload — `type` строки. Дроп на канву создаёт узел в точке сброса (координаты сцены).
- **Двойной клик** по строке = вставить блок в центр видимой области канвы (для любителей клавиатуры).
- Исполняемые и проектные блоки в одной палитре; исполняемые узлы образуют отдельную группу «Данные и код» (точка `ACCENT`).

### 5.3 Канва

- `QGraphicsView` + `QGraphicsScene`; сцена большая (−10000…+10000).
- **Сетка-точки**: рисуется в `drawBackground`: точки `GRID_DOT` каждые 20 px (плотность зависит от зума — при сильном отдалении шаг ×2, чтобы не слипалась в серость).
- **Зум**: Ctrl+колесо, 0.25…2.0, anchor под курсором (`AnchorUnderMouse`); Ctrl+0 — сброс в 1.0.
- **Пан**: средняя кнопка или Space+ЛКМ (CursorShape — ClosedHand в этот момент); обычное колесо — стандартная прокрутка.
- Подсказка в статус-баре видна при открытой вкладке (не блокирует — просто текст).

### 5.4 Узел (node_item) — точная анатомия

```
 верхняя полоса состояния 3 px (ACCENT / BORDER_SUBTLE / DANGER)
 ┌────────────────────────────────────┐
 │ Заголовок            10 pt, 16 px отступ слева │ ← header 24 px
 │ ●вход                        ●выход │ ← порты: 14 px ниже заголовка
 │ [inline-виджеты ...]               │
 │ чип значения — Consolas 9 pt       │
 └────────────────────────────────────┘
 ширина 200 px, высота под содержимое (мин 56 px), скругление 8, отступы 12
```

- **Полоса состояния**: исполняемый узел — `ACCENT`; проектный — `BORDER_SUBTLE`; ошибка — `DANGER`.
- **Порты**: кружки диаметром 9 px; вход слева (заливка `BG_ELEMENT`, контур `BORDER`), выход справа (заливка `TEXT_SECONDARY`); подключённый порт — заливка `ACCENT`. Подписи портов («да»/«нет» у branch, a/b у math — необязательно): 8 pt, `TEXT_MUTED`, рядом с портом.
- **Хит-зона порта** — радиус 12 px вокруг кружка (чтобы легко попадать).
- **Inline-виджеты** — `QGraphicsProxyWidget` в теле узла:
  - spin: ширина 70 px, высота 22 px; combo: 80×22; line: 130×22; code: 160×(rows×14) Consolas 9 pt; text: 160×(rows×14).
  - Изменение → событие → `project_service.set_param` (debounce пересчёта — движок, 200 мс).
  - **Важно (частая ошибка)**: proxy-виджеты перехватывают колесо мыши и двойные клики. Нужен `eventFilter`: колесо над inline-виджетом → передаётся канве как зум; двойной клик по телу узла открывает панель параметров, а клик по inline-виджету — не должен (работает сам виджет).
- **Чип значения** (под inline-виджетами или вместо них):
  - Consolas 9 pt; цвет `ACCENT` — живое значение, `TEXT_SECONDARY` — проектное/восстановленное, «—» — нет значения (пусто или ошибка выше).
  - Форматирование: списки/матрицы — до 5 строк (дальше «…»), каждая строка ≤48 символов (дальше «…»); `float` — как питоновский repr (6.0, 0.3333); комплексные — как repr.
  - У `result` — значение в прямоугольнике-чеке: фон `BG_ELEMENT`, скругление 6, паддинг 4×6, во всю ширину узла.
  - Пометка «устарело» (Live off): 8 pt, `TEXT_MUTED`, над чипом.
- **Выделение**: рамка 1.5 px `ACCENT` вокруг узла. Клик — выделить один; Ctrl+клик — добавить к выделению; выделение рамкой (rubber band) — группа.
- **Перемещение**: перетаскивание мышью; привязка к 10 px-сетке (координаты кратны 10); в модель пишется один раз при отпускании.

### 5.5 Связи (edge_item)

- Кривая: кубическая Безье: выход (x0,y0) → вход (x1,y1); контрольные точки — горизонтальные, смещение `max(40, 0.5*dx)` от каждого конца (та же форма, что в n8n/скрине).
- Перо: пунктир `[4, 4]`, ширина 1.4, цвет `BORDER`; hover — `TEXT_SECONDARY` (ширина 1.6); выбранная — `ACCENT`, ширина 2.
- Хит-зона вдоль кривой — 8 px (переопределить `shape()`).
- **Создание связи** (пошагово): 1) нажатие на выходной порт → временная связь к позиции мыши (цвет `BORDER`); 2) движение — линия следует за курсором, ближайшие входные порты подсвечиваются (`ACCENT`); 3) отпускание над входным портом — валидация `can_connect`: ок → создать; отказ (self/цикл) → тост с причиной, связи нет; 4) Esc/ПКМ в полёте — отмена.
- **Переподключение**: нажатие на существующую связь за её конец (вход) → связь отделена и тянется заново; отпускание в пустоте — связь удалена (standard n8n UX).
- **Замена**: drop на занятый вход — старая связь удалена, новая создана (правило один вход = одна связь).
- **Удаление**: выбор связи кликом → Delete.

### 5.6 Панель параметров (260 px)

- Ничего не выбрано: по центру «Выберите блок» (`TEXT_MUTED`).
- Выбран узел: заголовок = title (редактируемый `QLineEdit` — переименование), тип — Consolas 9 pt `TEXT_MUTED`, ниже форма: **все параметры** спека (даже inline) — `spin`/`line`/`text`/`combo`/`code` по таблице п. 2 SPEC_CORE; если ошибка — её текст внизу панели цветом `DANGER`.
- Кнопки внизу: «Дублировать» и «Удалить» (secondary и destructive-текст).
- Изменения применяются сразу (не по кнопке «Применить»): textEdited → set_param → debounce.

## 6. Вкладка «Идея»

| Элемент | Поведение |
|---|---|
| Поле названия | QLineEdit 16 pt, фон прозрачный, рамка появляется при фокусе |
| Метка «КРАТКАЯ ИДЕЯ» | uppercase 9 pt `TEXT_MUTED`; справа счётчик «0 / 280», обновляется живьём; >280 — счётчик `DANGER` (ввод не блокируется; обрезка — при сохранении) |
| Краткая идея | QPlainTextEdit, высота 64 px (3 строки), фон `BG_PANEL`, скругление 8 |
| Метка «ПОДРОБНОЕ ОПИСАНИЕ» + кнопка «Экспорт Markdown» | кнопка secondary, справа над полем |
| Подробное описание | QPlainTextEdit на всё оставшееся место, word wrap |
| Автосохранение | debounce 500 мс; по сохранению в статус-баре на 2 сек «Сохранено» (`TEXT_MUTED`) |
| Пустое состояние | нет проектов: центр «Создайте первый проект» + primary-кнопка повторяет «+ Новый» |

## 7. Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+N | новый проект |
| Ctrl+E | экспорт Markdown |
| Ctrl+= / Ctrl+- | зум канвы + / − |
| Ctrl+0 | сброс зума |
| F5 | пересчитать всё |
| Delete | удалить выбранное (узел/связь) |
| Esc | отмена создания связи; сброс выделения |
| Ctrl+D | дублировать выбранный узел |

## 8. Статус-бар и тосты

- Все короткие сообщения («Сохранено», «Цикл в схеме», «Схема не прочитана», «Не удалось сохранить») — в статус-баре, не в модальных окнах; время «Сохранено» — 2 сек.
- Модальные диалоги только: удаление проекта, выбор файла экспорта. Ничего другого.

## 9. Запрещено в UI (контроль качества)

- Хардкод цветов в виджетах — только theme.py.
- Яркие цвета, градиенты, тени, сплеш-скрины, оверлей-анимации.
- Модальный «детальный редактор узла» — не нужно, панель справа решает.
- Иконки из интернета; максимум — лаконичные inline-SVG монохромом `TEXT_SECONDARY`.
- QThread, фоновой рендер, «умные» анимации связей.
