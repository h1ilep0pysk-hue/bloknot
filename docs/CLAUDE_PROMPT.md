# Промт для Клода

> **Как пользоваться:** приложите Клоду эту папку со всеми документами и скопируйте текст между линиями `===` (лучше приложить и референс-скриншот Ryven). Промт короткий неслучайно: вся детализация теперь в спецификациях — Клод обязан их прочитать и выполнять буквально.

=======================================================================================

Ты пишешь приложение **Bloknot** на PySide6 — и интерфейс, и **исполняемую логику блоков** (dataflow). Работаешь прямо в текущей папке.

## Шаг 1. Прочитай спецификации (обязательно, до первой строчки кода)

В папке `docs/` лежат:

1. `ARCHITECTURE.md` — продукт, слои, сквозной пример, инварианты, частые ошибки.
2. `SPEC_CORE.md` — модели, порты, приведение типов, виджеты, контракт `fn`, полный реестр всех 21 блоков с формулами.
3. `SPEC_STORAGE.md` — SQLite, формат `schema_json` (**включая блок `runtime` со repr-значениями**), автосохранение, миграции.
4. `SPEC_FLOW.md` — движок: API, триггеры, псевдокод пересчёта подграфа, топосорт и циклы, песочница eval, ошибки как состояния узлов.
5. `SPEC_UI.md` — палитра цветов (hex), каждые панель/виджет/размер/состояние, горячие клавиши, что запрещено.

Выполняй спецификации буквально; если что-то противоречит или непонятно — спроси, не изобретай своё.

## Шаг 2. Референс визуала и поведения

Референс — скриншот нодового редактора Ryven (прилагается к промту; если его нет, прочитай описание в `ARCHITECTURE.md`, п. 1.2): узлы с цветной полосой сверху, пунктирные кривые-связи, живые значения моноширинным шрифтом прямо в телах узлов, eval-узел с inline-кодом (`inp[0][0]`), result-узлы со значением в прямоугольнике-чеке. Твоя канва должна **работать так же** — это вычисляющийся граф, а не нарисованная картинка.

## Шаг 3. Технические границы (жёстко)

- Python 3.11+, PySide6 ≥ 6.6. `requirements.txt`: только `pyside6` (+ комментарий про необязательный numpy).
- Никаких других внешних зависимостей; sqlite3/uuid/json/datetime — stdlib.
- `core/`, `services/`, `storage/` не импортируют PySide6; движок общается с UI колбэками.
- Приложение однопоточное; таймеры debounce (200 мс пересчёт, 500 мс запись) держит UI.
- Запуск: `python main.py` (Windows), окно 1280×800.

## Шаг 4. Инварианты (нарушение любого = брак)

1. Связь всегда выход → вход; self-связи запрещены; у входа максимум одна связь (новая заменяет старую).
2. Циклы запрещены: при попытке соединения — отказ с тостом «цикл в схеме»; при загрузке битого файла — узлы цикла получают ошибку и не считаются.
3. Значения вычисляет только движок (`flow_service`) из `fn` блоков; никаких «нарисованных» чисел.
4. Исключение в узле = состояние узла (полоса `DANGER`, текст в панели и тултипе), вниз уходят ошибки; приложение не падает.
5. Вход без связи = `None`; приведение типов делает движок до `fn` (правила SPEC_CORE, п. 4).
6. В `schema_json` хранятся только repr-строки значений (блок `runtime`); живые объекты (numpy и т.п.) в файл не попадают никогда.
7. Все цвета — константами из `ui/theme.py` (hex-таблица в SPEC_UI); ни один виджет не хардкодит цвет.
8. Параметры, помеченные `inline` в реестре, редактируются виджетами прямо в теле узла (через `QGraphicsProxyWidget`, с eventFilter против перехвата колеса) — и одновременно присутствуют в панели параметров.

## Шаг 5. Что собрать (структура файлов — как в `ARCHITECTURE.md`, п. 6)

`main.py`, `requirements.txt`, `.gitignore`, пакет `bloknot/` (app, core: models/ports/node_types/validation, storage: db/project_repository, services: project_service/schema_service/**flow_service**/export_service, ui: theme/main_window/projects_sidebar/idea_tab/schema_tab/params_panel + canvas: scene/canvas_view/node_item/edge_item/palette). Ничего не сокращай и не переименовывай: спецификации ссылаются на эти модули поимённо.

## Чек-лист приёмки (проверь каждый пункт построчно)

1. `python main.py` — окно открывается без ошибок и предупреждений в консоли.
2. Создание проекта; идея/описание вводятся; перезапуск — всё на месте.
3. **Живой dataflow**: `Число(2) → Оператор(**)` — в теле «Оператора» видно `4`; сменил spin на 3 → пересчиталось само (Live, 200 мс). `Число(3) → Оператор(**) → Результат` — в result-чеке значение.
4. `eval` с `expr=in0[0][0]` работает по цепочке как на референсе; `import` в выражении невозможен (проверь: ошибка узла, не краш).
5. Связь сама на себя отклонена; на входе одна связь (новая заменяет старую); попытка цикла — тост «цикл в схеме», связи нет.
6. Проектный блок (напр. «Парс HTML») вставлен в исполняемую цепочку — пересчёт не рвётся, его чип — строка-описание приглушённого цвета, полоса `BORDER_SUBTLE`.
7. Ошибка узла (деление на ноль / нечисловой вход / индекс вне диапазона) — полоса `DANGER`, текст в панели и тултипе; нижестоящие узлы показывают «—»; приложение живо.
8. numpy отсутствует → матричные узлы дают подсказку «установи numpy», без краха; с numpy `Матрица → Определитель` даёт число (аналог скрина).
9. Inline-виджеты: spin у «Числа», combo у «Оператора» (+−·÷**), code у `eval`, combo+line у «Ветки» — редактируются в теле узла; зум колесом над ними не «застревает» (eventFilter).
10. `branch` даёт два подписанных выхода «да»/«нет»; значение проходит через активную ветку.
11. Перезапуск: позиции узлов, связи, параметры и **repr-значения** восстановлены (чипы приглушённые до первого пересчёта); «Очистить значения» и «▶ Пересчитать всё» работают; тумблер «Авто» переключает режимы.
12. Пунктирные связи (штрих 4/4), hover/выбранные состояния; зум 25–200% Ctrl+колесом к курсору; пан средней кнопкой/Space+ЛКМ; привязка узлов к 10 px.
13. Экспорт Markdown: шаги схемы топологическим порядком + корректный Mermaid (проверь в рендере).
14. Визуал — строго по палитре SPEC_UI: лестница тёмно-серых, плоские скруглённые кнопки, uppercase-метки, Consolas для значений; ни одного яркого цвета, градиента, тени.

## Чего не делать

- Не рисовать муляж: любое значение в узле должно прийти из исполненного `fn`.
- Не подключать requests/BeautifulSoup/pandas — проектные блоки в v1 только описывают шаг; исполнение — фаза 2 (см. `ARCHITECTURE.md`, п. 9).
- Не выносить запись значений в БД отдельно и не писать на каждый кадр — только debounce 500 мс и repr.
- Не добавлять вкладки, настройки, облако, темы на выбор, стартовые шаблоны.
- Не трогать папку `docs/` (документация считается утверждённой).

Финал: краткий README с командой запуска и скрином-инструкцией в тексте («как собрать первую цепочку»), `requirements.txt`.
